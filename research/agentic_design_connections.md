\# Controls That Must Survive the Transition to Agents



\## Scope Control



The agent must know which tasks it is allowed to perform.



\---



\## Evidence Sufficiency



The agent should not act simply because retrieval returned something plausible.



\---



\## Source Authority



Active and authoritative sources should be distinguished from draft, superseded, stale, or unofficial information.



\---



\## Human Review



High-impact, ambiguous, or irreversible actions should require appropriate human oversight.



\---



\## Auditability



Tool calls, evidence, decisions, approvals, and outcomes should be traceable.



\---



\## Evaluation



Agent performance must be measured against controlled tasks and failure cases.



\---



\# Key Warning



Adding agency increases the consequences of mistakes.



A retrieval error may produce a bad answer.



An agent error may produce a bad action.



Therefore governance requirements should increase as system agency increases.
